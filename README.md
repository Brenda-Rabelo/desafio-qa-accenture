# Desafio QA Automation Accenture

Testes do DemoQA em Cypress com Cucumber e Page Object.

## Como executar

npm install
npx cypress open

No Cypress, escolha E2E e o Chrome. Os cenários estão em cypress/e2e/features.

## O que está coberto

- API da livraria: criar usuário, token, autorização, listar livros, alugar dois livros e consultar o usuário
- Formulário, janela, tabela, barra de progresso e ordenação
- Page Object das telas em cypress/pages
